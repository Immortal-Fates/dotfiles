# Main Takeaway
I use this repo to manage my dotfiles of different systems.

# Ubuntu
- Init
  
  ```
  chezmoi init --apply https://github.com/Immortal-Fates/dotfiles.git
  ```
- Synchronize
  ```
  chezmoi update
  ```

- Update
  ```
  chezmoi add ~/.*
  chezmoi diff
  chezmoi cd
  # use git to commit

  ```
